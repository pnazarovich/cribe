# Промпт для новой сессии Claude Code на другом Mac

## Что сделать руками (один шаг)

Скопировать папку проекта на новый Mac — например, через AirDrop папку `Transcriber`, **без** подпапок `.build`, `.ddata`, `dist` (это временные артефакты, ~2 ГБ).

Или по сети со старого Mac:

```bash
rsync -a --info=progress2 --exclude .build --exclude .ddata --exclude dist \
  ~/Documents/Cursor/Transcriber/ <user>@<newmac>.local:~/Transcriber/
```

Затем на новом Mac: `cd ~/Transcriber && claude` — и вставить промпт ниже.

---

## Промпт (скопировать целиком)

Ты настраиваешь и запускаешь на этом Mac уже готовое приложение Transcriber — macOS-диктовку (Swift, SPM, без .xcodeproj). Код лежит в текущей папке. Сделай всё сам, спрашивай только там, где нужны мои клики в системных диалогах.

КОНТЕКСТ ПРОЕКТА
- Menu-bar приложение: правый ⌘ — диктовка, правый ⌥ — диктовка с переводом на английский, Esc — отмена. Локальное распознавание Whisper (WhisperKit/CoreML) для русского и украинского, словарь терминов (латиница в кириллической речи), пост-обработка через GPT (OpenAI API-key или вход через аккаунт ChatGPT), стеклянная плашка-HUD, карточки диктовок при отсутствии поля ввода.
- Сборка ТОЛЬКО через `bash scripts/build-app.sh` (внутри xcodebuild по Package.swift + подпись). НЕ `swift build` для .app — ресурс-бандл KeyboardShortcuts иначе ломается в рантайме. `swift build`/`swift test` годятся для библиотеки и тестов.
- Спека и план: `docs/superpowers/specs/2026-07-31-transcriber-design.md`, `docs/superpowers/plans/2026-07-31-transcriber.md`. Исследование моделей: `docs/research/`.

ЗАДАЧИ ПО ПОРЯДКУ
1. Проверь окружение: `xcodebuild -version` (нужен Xcode; если нет — скажи мне, я поставлю), `swift --version` (нужен Swift 6.x), архитектура arm64, macOS 14+.
2. Подпись: выполни `security find-identity -v -p codesigning`. Если есть «Apple Development: …» — подставь эту строку целиком в `scripts/build-app.sh` вместо текущей. Если сертификатов нет — замени имя на одиночный дефис `-` (ad-hoc) и предупреди меня, что при каждой пересборке придётся заново выдавать разрешения.
3. Собери и проверь: `swift test` (ожидается ~222 теста, 0 падений), затем `bash scripts/build-app.sh` (ожидается `OK: dist/Transcriber.app`). Если что-то падает — чини сам, это рабочий проект, а не заготовка.
4. Установи: `cp -R dist/Transcriber.app /Applications/ && open /Applications/Transcriber.app`. Убедись, что процесс жив (`pgrep -x Transcriber`) и иконка-волна в меню-баре есть (`osascript -e 'tell application "System Events" to get name of every menu bar item of menu bar 2 of process "Transcriber"'`). Если иконки не видно из-за переполненного меню-бара — сдвинь её: `defaults write online.nazarovych.transcriber "NSStatusItem Preferred Position Item-0" -float 120` и перезапусти приложение.
5. Данные: если я скопировал `~/Library/Application Support/Transcriber/` со старого Mac — проверь, что `dictionary.json` читается и содержит записи, а `sounds/start.*`/`stop.*` на месте. Если папки нет — ничего не делай, приложение создаст словарь по умолчанию само.
6. Скажи мне, что нужно нажать руками: (а) разрешение микрофона и Accessibility через меню волны → «Первичная настройка…» (системные диалоги — только я), (б) если модели не скопированы, там же «Скачать» (~4.5 ГБ, потом каждая модель один раз компилируется под нейродвижок — это нормально, до пары минут), (в) авторизация в Настройках → AI (ключ или вход через ChatGPT) — Keychain со старого Mac не переносится.
7. После того как я выдам разрешения — проверь работу без моего участия: собери CLI-фикстуру и прогони конвейер:
   `say -v Milena "Сделай коммит и задеплой на гитхаб через докер" -o /tmp/fx.aiff && swift run TranscriberCLI /tmp/fx.aiff --lang ru --no-gpt`
   В выводе термины должны быть латиницей (commit/deploy/GitHub/Docker). Покажи мне результат.

ПРАВИЛА РАБОТЫ
- Не переписывай архитектуру и не «улучшай» код — задача только запустить и проверить.
- Ничего не публикуй наружу и не отправляй данные никуда, кроме OpenAI при моей явной авторизации.
- Если появится новая идея по фиче — предложи, но не делай без моего «да».
- Известные особенности, не считать багами: в браузерах диктовка всегда вставляется (Chrome снаружи не даёт понять, есть ли фокус в поле); первый запуск каждой модели долгий из-за компиляции CoreML; при выключенной «естественной прокрутке» смахивание карточек идёт в обратную сторону.
