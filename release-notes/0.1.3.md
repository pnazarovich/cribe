# Индикатор громкости

- Столбики больше не встают на максимум при включении. Первые сто тридцать миллисекунд микрофон ещё просыпается и отдаёт не звук, а падение в цифровую тишину; шкала калибровалась по нему и уезжала так, что настоящая речь оказывалась у верхнего края. Теперь начало записи в расчёт не идёт.

# Модель

- «Готовлю модель…» больше не встречает первую диктовку: модель поднимается в память сразу при запуске приложения. Если она ещё не скачана, прогрев молчит.
