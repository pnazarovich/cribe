# Esc отменяет диктовку — и только её

Раньше Esc во время записи отменял диктовку и вдобавок уходил в открытое приложение.
Если вы диктовали в Claude Code или другой инструмент, где Esc что-то прерывает, вместе
с диктовкой прерывалась и его работа.

Теперь, пока идёт запись, Cribe забирает Esc себе целиком. Вне записи Esc работает
как обычно.
