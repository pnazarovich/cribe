# Перевод по правому ⌥ больше не зависит от входа в ChatGPT

- Раньше без авторизации ChatGPT перевод молча не выполнялся — вставлялся русский текст. Теперь ChatGPT переводит первым (качество выше), а если он недоступен, переводит сама модель, и приложение предупреждает: «перевод без ChatGPT — качество ниже».
- Для перевода моделью нужна полная модель large-v3: быстрая turbo-модель переводить не умеет.
