# Первый публичный выпуск

- Локальная диктовка на русском и украинском: правый ⌘ — говорите, текст появляется в поле ввода.
- Правый ⌥ — диктовка с переводом на английский, Esc — отмена.
- Распознавание целиком на Mac (Whisper через WhisperKit, Apple Neural Engine); звук никуда не уходит.
- Словарь терминов, история диктовок, карточки для случаев, когда поля ввода нет.
- Необязательная чистка пунктуации через GPT — только если вы её включили.
