# Починки

- Ключ OpenAI сохраняется сам — по уходу из поля и при закрытии настроек, а не только по кнопке. Раньше введённый ключ мог не попасть в связку ключей вовсе.
- Индикатор громкости больше не вспыхивает на максимум в первые полсекунды записи: шкала калибруется по медиане первых замеров, а не по самому тихому из них (первые буферы микрофона бывают пустыми).
- Краб вместо системной волны в словаре и на карточке диктовки.
